# Archived BRIEF / PLAN docs

Internal dev notes from finished sshc cycles (v0.2 — v0.12).

These were the per-cycle architecture briefs and execution plans
that lived in the repo root while the cycle was active. They are
kept here for historical context — the actual decisions are already
captured in the matching CHANGELOG entries and the v* git tags, so
this is a *secondary* reference. Treat the files as a snapshot of
what was true at the time the BRIEF was authored; later git history
overrides anything contradicted in code.

The active cycle's BRIEF / PLAN / TODO live in the repo root and
stay gitignored until the cycle finishes; once it tags out, the
docs get moved here and the next cycle starts.
